# ttsbard Echo

ttsbard Echo — Windows-приложение для получения событий от серверов по SSE и отображения активности подключений в компактном плавающем окне.

## Альфа-версия

Текущая версия: **v0.1.0**. Это ранняя альфа-версия: возможны несовместимые изменения. Перед тестированием сохраните резервную копию настроек подключений.

## Использование

Краткая инструкция находится в [руководстве пользователя](docs/user/README.md). Echo требует HTTP(S)-адрес SSE-потока и, при необходимости, токен доступа.
