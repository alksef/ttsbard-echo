# Roadmap ttsbard Echo

Здесь хранятся roadmap следующих этапов развития приложения. Каждый roadmap должен описывать самостоятельную цель, границы задачи, зависимости, критерии готовности и проверки.

## Статусы

- `active/` — текущие согласованные задачи развития. Каталог создаётся при появлении нового roadmap.
- `completed/` — завершённые задачи и программы.
- `rejected/` — рассмотренные, но отклонённые направления.

Сейчас активных roadmap нет. Программа подготовки интерфейса к альфа-релизу `v0.1.0` завершена и находится в [completed](completed/README.md).

## Правила работы

1. Перед началом проверить актуальное состояние кода и документации.
2. Не смешивать независимые направления развития в одном roadmap.
3. Указать проверяемые критерии готовности.
4. После завершения перенести roadmap в `completed/` и записать фактический результат.
